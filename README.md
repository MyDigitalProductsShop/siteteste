# LUCI4 WRATH — Site da loja

## Abrir no VS Code

1. Abra esta pasta no VS Code.
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).
3. Edite o catálogo de produtos no começo do arquivo `app.js`.
4. Edite as cores, tamanhos, cabeçalho e layout no `styles.css`.
5. Imagens da capa e logos estão em `assets/`.

## Arquivos

- `index.html`: estrutura principal da loja
- `app.js`: catálogo, páginas, pesquisa e carrinho
- `styles.css`: estilos visuais, layout e responsividade
- `assets/`: imagens da marca

> Esta é uma versão demonstrativa. O checkout real precisa de integração com um provedor de pagamento. As imagens dos produtos são ilustrativas.
